# WebAssembly npm package — 2026-09-20

## Architecture

- This entry supersedes the N-API and five-platform npm release design in the
  2026-09-19 entries and the N-API validation note in the fixed-codebook entry.
- `bindings/wasm` is the only JavaScript binding. `wasm-bindgen` produces one
  `wasm32-unknown-unknown` module for the npm package.
- The npm package uses conditional exports. Node reads the module bytes from
  the installed package; browsers fetch the same module. Module initialization
  completes during import, so `encode`, `decode`, `encodeBatch` and
  `decodeBatch` remain synchronous for callers.
- `xtask` builds and publishes one npm package. Platform `.node` packages,
  provenance files and artifact collection are gone.
- `wasm-opt` is disabled in package metadata because an older external
  Binaryen can reject valid output from a newer Rust compiler. Rust release
  optimization still runs.
- `wasm-pack` may install the `wasm-bindgen-cli` version matching `Cargo.lock`.
  Do not use `--mode no-install`; clean CI runners do not already have that CLI.
- The root workspace version is shared by the public Rust crate, the binding
  crate and the generated npm package.
- The public npm name is `@levish0/readable-uuid`; the Rust crate remains
  `readable-uuid`. npm rejected the unscoped package name because it is too
  similar to the existing `readableuuid` package.

## Validation

- Rust tests, formatting and Clippy passed, including WASM-target Clippy.
- TypeScript, Prettier, ESLint and four Node tests passed against the generated
  WASM package.
- A packaged tarball installed in a clean pnpm consumer and passed single and
  batch round trips. Its declarations passed a separate TypeScript consumer
  check. The installed package also passed a round trip on Node.js 20.20.2.
- Chrome loaded the browser entry and WASM over HTTP and completed a UUID
  round trip.
- `just release-dry --allow-dirty` passed for both registries without native
  artifacts. crates.io already contains 0.1.0 while npm has no package; the
  published crate's core, codebook, tests and format match the current source,
  so `@levish0/readable-uuid` 0.1.0 can be published with `just publish-npm`.
- On the recorded Windows machine, WASM median encode/decode were 881 ns and
  4,186 ns. See `docs/performance.md` for peer results.
